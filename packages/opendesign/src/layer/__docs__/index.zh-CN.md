## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-layer-position | 浮层定位方式 |
| \-\-layer-mask | 浮层遮罩颜色 |
| \-\-layer-align | 浮层水平对齐方式 |
| \-\-layer-justify | 浮层垂直对齐方式 |
| \-\-layer-origin | 浮层动画原点 |
| \-\-layer-z-index ⚠ 运行时赋值 | 浮层层级（由 createTopZIndex() 动态分配，CSS 覆盖无效） |
