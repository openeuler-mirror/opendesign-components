## API

### CSS 变量

| CSS Variables                           | Description                                                                          |
| --------------------------------------- | ------------------------------------------------------------------------------------ |
| \-\-layer-position                      | Layer positioning mode                                                               |
| \-\-layer-mask                          | Layer mask color                                                                     |
| \-\-layer-align                         | Layer horizontal alignment                                                           |
| \-\-layer-justify                       | Layer vertical alignment                                                             |
| \-\-layer-origin                        | Layer animation origin                                                               |
| \-\-layer-z-index ⚠ Runtime assignment | Layer z-index (dynamically allocated by createTopZIndex(), CSS override ineffective) |
