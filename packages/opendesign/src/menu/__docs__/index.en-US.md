## API

### CSS Variables

| CSS Variable | Description |
| --- | --- |
| \-\-menu-width | Menu width |
| \-\-menu-bg-color | Menu background color |
| \-\-menu-indicator-width | Menu indicator width |
| \-\-menu-indicator-bg-color | Menu indicator background color |
| \-\-menu-max-row | Menu maximum rows |
| \-\-menu-color | Menu text color |
| \-\-menu-color-disabled | Menu text color in disabled state |
| \-\-menu-color-selected | Menu text color when selected |
| \-\-menu-bg-color-hover | Menu background color on hover |
| \-\-menu-bg-color-selected | Menu background color when selected |
| \-\-menu-icon-color | Menu icon color |
| \-\-menu-icon-color-selected | Menu icon color when selected |
| \-\-menu-base-indent | Menu base indent |
| \-\-menu-item-padding-v | Menu item vertical padding |
| \-\-menu-padding-h | Menu horizontal padding |
| \-\-menu-radius | Menu border radius |
| \-\-menu-text-size | Menu text size |
| \-\-menu-text-height | Menu text line height |
| \-\-menu-icon-size | Menu icon size |
| \-\-menu-icon-gap | Menu icon gap |
| \-\-menu-arrow-size | Menu arrow size |
| \-\-menu-level-indent | Menu level indent |
| \-\-menu-popover-width | Menu popover width |
| \-\-menu-level ⚠ Runtime assignment | Menu item depth level (computed internally based on nesting level, CSS override ineffective) |
