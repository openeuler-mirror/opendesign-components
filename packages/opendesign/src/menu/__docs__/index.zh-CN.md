## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-menu-width | 菜单宽度 |
| \-\-menu-bg-color | 菜单背景色 |
| \-\-menu-indicator-width | 菜单指示器宽度 |
| \-\-menu-indicator-bg-color | 菜单指示器背景色 |
| \-\-menu-max-row | 菜单最大行数 |
| \-\-menu-color | 菜单文字颜色 |
| \-\-menu-color-disabled | 菜单禁用文字颜色 |
| \-\-menu-color-selected | 菜单选中文字颜色 |
| \-\-menu-bg-color-hover | 菜单鼠标悬停背景色 |
| \-\-menu-bg-color-selected | 菜单选中背景色 |
| \-\-menu-icon-color | 菜单图标颜色 |
| \-\-menu-icon-color-selected | 菜单选中图标颜色 |
| \-\-menu-base-indent | 菜单基础缩进 |
| \-\-menu-item-padding-v | 菜单项垂直内边距 |
| \-\-menu-padding-h | 菜单水平内边距 |
| \-\-menu-radius | 菜单圆角 |
| \-\-menu-text-size | 菜单文字大小 |
| \-\-menu-text-height | 菜单文字行高 |
| \-\-menu-icon-size | 菜单图标大小 |
| \-\-menu-icon-gap | 菜单图标间距 |
| \-\-menu-arrow-size | 菜单箭头大小 |
| \-\-menu-level-indent | 菜单层级缩进 |
| \-\-menu-popover-width | 菜单弹出层宽度 |
| \-\-menu-level ⚠ 运行时赋值 | 菜单项层级深度（由组件内部根据嵌套层级计算赋值，CSS 覆盖无效） |
