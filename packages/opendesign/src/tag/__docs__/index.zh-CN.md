## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| --tag-radius | 标签圆角 |
| --tag-color | 标签文字颜色 |
| --tag-bg-color | 标签背景色 |
| --tag-bd-color | 标签边框颜色 |
| --tag-icon-close-color | 标签关闭图标颜色 |
| --tag-icon-close-color-hover | 标签关闭图标颜色(hover) |
| --tag-icon-close-color-active | 标签关闭图标颜色(active) |
| --tag-padding | 标签内边距 |
| --tag-text-size | 标签文字字号 |
| --tag-text-height | 标签文字行高 |
| --tag-height | 标签高度 |
| --tag-icon-size | 标签图标尺寸 |
| --tag-icon-gap | 标签图标间距 |
