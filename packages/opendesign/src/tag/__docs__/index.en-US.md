## API

### CSS Variables

| CSS Variable                           | Description                          |
| -------------------------------------- | ------------------------------------ |
| --tag-radius                           | Tag border radius                    |
| --tag-height                           | Tag height                           |
| --tag-padding                          | Tag padding                          |
| --tag-color                            | Tag text color                       |
| --tag-color-hover ^[1.2.6](primary)    | Tag text color (hover)               |
| --tag-bg-color                         | Tag background color                 |
| --tag-bg-color-hover ^[1.2.6](primary) | Tag background color (hover)         |
| --tag-bg-image ^[1.2.6](primary)       | Tag background image (e.g. gradient) |
| --tag-bd ^[1.2.6](primary)             | Tag border (width/style/color)       |
| --tag-bd-color                         | Tag border color                     |
| --tag-bd-color-hover ^[1.2.6](primary) | Tag border color (hover)             |
| --tag-icon-close-color                 | Tag close icon color                 |
| --tag-icon-close-color-hover           | Tag close icon color (hover)         |
| --tag-icon-close-color-active          | Tag close icon color (active)        |
| --tag-icon-size                        | Tag icon size                        |
| --tag-icon-gap                         | Tag icon gap                         |
| --tag-text-size                        | Tag text font size                   |
| --tag-text-height                      | Tag text line height                 |
