## Api

### CSS 变量

| CSS 变量                                             | 描述                                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------ |
| \-\-upload-progress-height ^[1.2.0](primary)         | 进度条高度                                                                           |
| \-\-upload-progress-radius ^[1.2.0](primary)         | 进度条圆角                                                                           |
| \-\-upload-progress-bg-color ^[1.2.0](primary)       | 进度条背景色                                                                         |
| \-\-upload-progress-value-bg-color ^[1.2.0](primary) | 进度条填充色                                                                         |
| \-\-upload-icon-size                                 | 图标尺寸                                                                             |
| \-\-upload-color                                     | 文字颜色                                                                             |
| \-\-upload-item-radius                               | 上传项圆角                                                                           |
| \-\-upload-drag-padding                              | 拖拽区域内边距                                                                       |
| \-\-upload-drag-radius                               | 拖拽区域圆角                                                                         |
| \-\-upload-card-radius                               | 卡片圆角                                                                             |
| \-\-upload-card-width                                | 卡片宽度                                                                             |
| \-\-upload-card-img-fit ^[1.2.5](primary)            | 卡片缩略图填充方式（cover &vert; contain &vert; fill &vert; none &vert; scale-down） |
