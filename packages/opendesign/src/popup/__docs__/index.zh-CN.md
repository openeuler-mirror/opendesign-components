## Api

### CSS 变量

| CSS 变量              | 描述                                                     |
| --------------------- | -------------------------------------------------------- |
| \-\-popup-bg-color    | 弹层背景色                                               |
| \-\-popup-shadow      | 弹层阴影                                                 |
| \-\-popup-radius      | 弹层圆角                                                 |
| \-\-popup-bd          | 弹层边框                                                 |
| \-\-popup-padding     | 弹层内边距                                               |
| \-\-popup-edge-offset | 弹层与视口边缘的最小距离（由 `edgeOffset` 属性计算注入） |
