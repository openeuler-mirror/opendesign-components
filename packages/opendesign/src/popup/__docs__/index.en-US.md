## Api

### CSS Variables

| CSS Variable          | Description                                                                                    |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| \-\-popup-bg-color    | Popup background color                                                                         |
| \-\-popup-shadow      | Popup shadow                                                                                   |
| \-\-popup-radius      | Popup border radius                                                                            |
| \-\-popup-bd          | Popup border                                                                                   |
| \-\-popup-padding     | Popup padding                                                                                  |
| \-\-popup-edge-offset | Minimum distance between the popup and the viewport edge (computed from the `edgeOffset` prop) |
