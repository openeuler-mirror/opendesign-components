## API

### CSS 变量

| CSS 变量                               | 描述             | 默认值                    |
| -------------------------------------- | ---------------- | ------------------------- |
| `--search-prefix-width` | 头部筛选框宽度   | `136px`                   |
| `--search-suffix-width` | 尾部筛选框宽度   | `100px`                   |
| `--search-input-width`  | 搜索输入框宽度   | `320px`                   |
| `--search-icon-size`    | 搜索图标尺寸     | `var(--o-icon_size-m)`    |
