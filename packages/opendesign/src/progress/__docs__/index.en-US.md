## Api

### CSS 变量

| CSS Variables | Description |
| --- | --- |
| \-\-progress-track-bg-color | Progress track background color |
| \-\-progress-color | Progress color |
| \-\-progress-label-gap | Spacing between progress label and bar |
| \-\-progress-inner-label-color | Progress inner label text color |
| \-\-progress-inner-label-gap | Progress inner label spacing |
| \-\-progress-text-size | Progress text size (effective under medium/small size) |
| \-\-progress-text-height | Progress text line height (effective under medium/small size) |
| \-\-progress-icon-size | Progress icon size (effective under medium/small size) |
| \-\-progress-bar-bg-color | Progress bar background color (effective under primary/success/warning/danger type) |
| \-\-progress-circle-bar-bg-color | Circle progress bar background color (effective under primary/success/warning/danger type) |
| \-\-progress-icon-color | Progress icon color (effective under primary/success/warning/danger type) |
