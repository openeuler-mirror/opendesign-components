## Api

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-progress-track-bg-color | 进度条轨道背景色 |
| \-\-progress-color | 进度条颜色 |
| \-\-progress-label-gap | 进度条标签与条之间的间距 |
| \-\-progress-inner-label-color | 进度条内部标签文字颜色 |
| \-\-progress-inner-label-gap | 进度条内部标签间距 |
| \-\-progress-text-size | 进度条文字大小（medium/small 尺寸下各自生效） |
| \-\-progress-text-height | 进度条文字行高（medium/small 尺寸下各自生效） |
| \-\-progress-icon-size | 进度条图标大小（medium/small 尺寸下各自生效） |
| \-\-progress-bar-bg-color | 进度条条背景色（primary/success/warning/danger 类型下各自生效） |
| \-\-progress-circle-bar-bg-color | 圆形进度条背景色（primary/success/warning/danger 类型下各自生效） |
| \-\-progress-icon-color | 进度条图标颜色（primary/success/warning/danger 类型下各自生效） |
