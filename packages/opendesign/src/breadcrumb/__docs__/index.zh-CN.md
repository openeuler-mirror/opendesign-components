## Api

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-breadcrumb-color | 面包屑文字颜色 |
| \-\-breadcrumb-color-hover | 面包屑文字 hover 颜色 |
| \-\-breadcrumb-color-active | 面包屑文字激活颜色 |
| \-\-breadcrumb-color-selected | 面包屑选中项文字颜色 |
| \-\-breadcrumb-text-size | 面包屑文字大小 |
| \-\-breadcrumb-text-height | 面包屑文字行高 |
| \-\-breadcrumb-gap | 面包屑项之间的间距 |
| \-\-breadcrumb-separator-size | 面包屑分隔符大小 |
| \-\-breadcrumb-label-max-width | 面包屑标签最大宽度 |
