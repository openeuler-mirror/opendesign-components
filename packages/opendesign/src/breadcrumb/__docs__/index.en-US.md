### CSS 变量

| CSS Variables | Description |
| --- | --- |
| \-\-breadcrumb-color | Breadcrumb text color |
| \-\-breadcrumb-color-hover | Breadcrumb text hover color |
| \-\-breadcrumb-color-active | Breadcrumb text active color |
| \-\-breadcrumb-color-selected | Breadcrumb selected item text color |
| \-\-breadcrumb-text-size | Breadcrumb text size |
| \-\-breadcrumb-text-height | Breadcrumb text line height |
| \-\-breadcrumb-gap | Spacing between breadcrumb items |
| \-\-breadcrumb-separator-size | Breadcrumb separator size |
| \-\-breadcrumb-label-max-width | Breadcrumb label maximum width |
