## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-textarea-min-height | 文本域最小高度 |
| \-\-textarea-min-width | 文本域最小宽度 |
| \-\-textarea-padding-v | 文本域垂直内边距（small/medium/large 尺寸下各自生效） |
| \-\-textarea-padding-h | 文本域水平内边距（small/medium/large 尺寸下各自生效） |
| \-\-textarea-color | 文本域文字颜色（text 变体下，success/warning/danger 状态生效） |
| \-\-textarea-color-disabled | 文本域禁用状态文字颜色（text 变体下，success/warning/danger 状态生效） |
