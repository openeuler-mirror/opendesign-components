## Api

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-_box-padding-y | 输入框垂直内边距 |
| \-\-_box-padding-x | 输入框水平内边距 |
| \-\-_box-padding | 输入框内边距，由垂直和水平内边距组合：`var(--_box-padding-y) var(--_box-padding-x)` |
| \-\-_box-height | 输入框高度 |
| \-\-input-icon-size | 输入框图标大小（large 尺寸下生效） |
| \-\-input-color | 输入框文字颜色（text 变体下，success/warning/danger 状态生效） |
| \-\-input-color-disabled | 输入框禁用状态文字颜色（text 变体下，success/warning/danger 状态生效） |
