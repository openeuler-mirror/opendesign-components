## Api

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-badge-text-size | 徽标文字大小 |
| \-\-badge-text-height | 徽标文字行高 |
| \-\-badge-radius | 徽标圆角 |
| \-\-badge-padding | 徽标内边距 |
| \-\-badge-min-width | 徽标最小宽度 |
| \-\-badge-dot-size | 徽标圆点大小 |
| \-\-badge-height | 徽标高度 |
| \-\-badge-color | 徽标文字颜色（primary/success/warning/danger 类型下各自生效） |
| \-\-badge-bg-color | 徽标背景色（primary/success/warning/danger 类型下各自生效） |
