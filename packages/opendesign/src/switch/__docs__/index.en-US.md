## API

### CSS Variables

| CSS Variable | Description |
| --- | --- |
| \-\-switch-radius | Border radius |
| \-\-switch-color | Text color |
| \-\-switch-bg-color | Default background color |
| \-\-switch-bg-color-hover | Default background color (hover) |
| \-\-switch-bg-color-active | Default background color (active) |
| \-\-switch-bg-color-disabled | Default background color (disabled) |
| \-\-switch-bg-color-checked | Checked background color |
| \-\-switch-bg-color-checked-hover | Checked background color (hover) |
| \-\-switch-bg-color-checked-active | Checked background color (active) |
| \-\-switch-bg-color-checked-disabled | Checked background color (disabled) |
| \-\-switch-handler-bg-color | Handler background color |
| \-\-switch-handler-bg-color-disabled | Handler background color (disabled) |
| \-\-switch-handler-bg-color-checked-disabled | Handler background color when checked (disabled) |
| \-\-switch-icon-loading-color | Loading icon color |
| \-\-switch-icon-size ^[1.2.2](primary) | Custom icon size |
| \-\-switch-min-width | Minimum width |
| \-\-switch-size | Switch size |
| \-\-switch-text-size ^[1.2.2](primary) | Text size (medium size) |
| \-\-switch-text-height | Text line height |
| \-\-switch-handler-size | Handler size |
| \-\-switch-handler-offset | Handler offset |
| \-\-switch-label-padding | Text padding |
