## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-switch-radius | 圆角值 |
| \-\-switch-color | 文字颜色 |
| \-\-switch-bg-color | 默认背景色 |
| \-\-switch-bg-color-hover | 默认背景色(hover) |
| \-\-switch-bg-color-active | 默认背景色(active) |
| \-\-switch-bg-color-disabled | 默认背景色(disabled) |
| \-\-switch-bg-color-checked | 选中背景色 |
| \-\-switch-bg-color-checked-hover | 选中背景色(hover) |
| \-\-switch-bg-color-checked-active | 选中背景色(active) |
| \-\-switch-bg-color-checked-disabled | 选中背景色(disabled) |
| \-\-switch-handler-bg-color | 滑块背景色 |
| \-\-switch-handler-bg-color-disabled | 滑块背景色(disabled) |
| \-\-switch-handler-bg-color-checked-disabled | 选中时滑块背景色(disabled) |
| \-\-switch-icon-loading-color | loading图标颜色 |
| \-\-switch-icon-size ^[1.2.2](primary) | 自定义图标大小 |
| \-\-switch-min-width | 最小宽度 |
| \-\-switch-size | 开关尺寸 |
| \-\-switch-text-size ^[1.2.2](primary) | 文字大小(medium尺寸) |
| \-\-switch-text-height | 文字行高 |
| \-\-switch-handler-size | 滑块尺寸 |
| \-\-switch-handler-offset | 滑块偏移 |
| \-\-switch-label-padding | 文字内边距 |
