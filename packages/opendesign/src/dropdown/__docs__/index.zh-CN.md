| CSS 变量 | 描述 |
| --- | --- |
| \-\-dropdown-list-bg-color | 下拉列表背景色 |
| \-\-dropdown-list-shadow | 下拉列表阴影 |
| \-\-dropdown-list-bd | 下拉列表边框 |
| \-\-dropdown-list-radius | 下拉列表圆角 |
| \-\-dropdown-list-padding | 下拉列表内边距 |
| \-\-dropdown-item-color | 下拉项文字颜色 |
| \-\-dropdown-item-color-hover | 下拉项鼠标悬停文字颜色 |
| \-\-dropdown-item-color-disabled | 下拉项禁用文字颜色 |
| \-\-dropdown-item-bg-color | 下拉项背景色 |
| \-\-dropdown-item-bg-color-hover | 下拉项鼠标悬停背景色 |
| \-\-dropdown-item-bg-color-disabled | 下拉项禁用背景色 |
| \-\-dropdown-item-text-size | 下拉项文字大小 |
| \-\-dropdown-item-text-height | 下拉项文字行高 |
| \-\-dropdown-item-justify | 下拉项内容对齐方式 |
| \-\-dropdown-item-padding | 下拉项内边距 |
