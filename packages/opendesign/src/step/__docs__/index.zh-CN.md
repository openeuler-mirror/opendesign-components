### CSS 变量

| CSS 变量 | 默认值 | 描述 |
| --- | --- | --- |
| --step-item-head-size | var(--o-font_size-h4) | 步骤头文字大小 |
| --step-item-head-height | var(--o-line_height-h4) | 步骤头文字行高 |
| --step-item-title-size | var(--o-font_size-text1) | 标题文字大小 |
| --step-item-title-height | var(--o-line_height-text1) | 标题文字行高 |
| --step-item-title-font-weight | normal | 标题文字粗细 |
| --step-item-desc-size | var(--o-font_size-tip2) | 描述文字大小 |
| --step-item-desc-height | var(--o-line_height-tip2) | 描述文字行高 |
| --step-item-head-width | var(--o-icon_size_control-l) | 步骤图标容器宽度 |
| --step-item-icon-size | var(--o-icon_size-m) | 步骤图标大小 |
| --step-item-gap | 8px | 步骤项间距 |
| --step-item-main-gap | 8px | 主内容间距 |
| --step-item-desc-gap | 4px | 描述间距 |
| --step-item-line-gap | 8px | 连接线间距 |
| --step-item-line-height | 1px | 连接线高度 |
| --step-item-align | center | 步骤项对齐方式 |
| --step-item-head-bg | var(--o-color-success1) | 步骤头背景色 |
| --step-item-head-color | var(--o-color-white) | 步骤头文字颜色 |
| --step-item-title-color | var(--o-color-info2) | 标题文字颜色 |
| --step-item-desc-color | var(--o-color-info3) | 描述文字颜色 |
| --step-item-line-bg | var(--o-color-control4) | 连接线背景色 |
| --step-item-main-padding | 0 12px | 主内容内边距 |
| --o-step-item-left ⚠ 运行时赋值 | - | 步骤条分隔线左偏移（由组件内部根据 DOM 尺寸计算，CSS 覆盖无效） |
| --o-step-item-right ⚠ 运行时赋值 | - | 步骤条分隔线右偏移（同上） |
| --o-step-item-top ⚠ 运行时赋值 | - | 步骤条分隔线上偏移（同上） |
| --o-step-item-bottom ⚠ 运行时赋值 | - | 步骤条分隔线下偏移（同上） |
