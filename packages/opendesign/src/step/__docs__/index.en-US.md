| CSS Variable | Default | Description |
| --- | --- | --- |
| --step-item-head-size | var(--o-font_size-h4) | Step head text size |

| --step-item-title-size | var(--o-font_size-text1) | Title text size |
| --step-item-title-height | var(--o-line_height-text1) | Title text line height |
| --step-item-title-font-weight | normal | Title text font weight |
| --step-item-desc-size | var(--o-font_size-tip2) | Description text size |
| --step-item-desc-height | var(--o-line_height-tip2) | Description text line height |
| --step-item-head-width | var(--o-icon_size_control-l) | Step icon container width |
| --step-item-icon-size | var(--o-icon_size-m) | Step icon size |
| --step-item-gap | 8px | Step item gap |
| --step-item-main-gap | 8px | Main content gap |
| --step-item-desc-gap | 4px | Description gap |
| --step-item-line-gap | 8px | Connector line gap |
| --step-item-line-height | 1px | Connector line height |
| --step-item-align | center | Step item alignment |
| --step-item-head-bg | var(--o-color-success1) | Step head background color |
| --step-item-head-color | var(--o-color-white) | Step head text color |

| --o-step-item-bottom ⚠ Runtime assignment | - | Step separator bottom offset (same as above) |
