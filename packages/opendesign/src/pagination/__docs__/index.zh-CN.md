## API

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-pagination-item-size | 分页项尺寸 |
| \-\-pagination-arrow-size | 分页箭头尺寸 |
| \-\-pagination-item-gap | 分页项间距 |
| \-\-pagination-item-sm-gap | 分页小尺寸项间距 |
| \-\-pagination-item-size-gap | 分页项尺寸间距 |
| \-\-pagination-arrow-color | 分页箭头颜色 |
| \-\-pagination-arrow-color-hover | 分页箭头鼠标悬停颜色 |
| \-\-pagination-arrow-color-active | 分页箭头鼠标按下颜色 |
| \-\-pagination-arrow-color-disabled | 分页箭头禁用颜色 |
| \-\-pagination-item-color | 分页项文字颜色 |
| \-\-pagination-item-bg-color | 分页项背景色 |
| \-\-pagination-item-bg-color-hover | 分页项鼠标悬停背景色 |
| \-\-pagination-item-bg-color-active | 分页项鼠标按下背景色 |
| \-\-pagination-item-bg-color-current | 当前页背景色 |
| \-\-pagination-item-bd-color | 分页项边框颜色 |
| \-\-pagination-item-color-hover | 分页项鼠标悬停文字颜色 |
| \-\-pagination-item-color-active | 分页项鼠标按下文字颜色 |
| \-\-pagination-item-color-current | 当前页文字颜色 |
| \-\-pagination-item-bd-color-disabled | 分页项禁用边框颜色 |
| \-\-pagination-radius | 分页圆角 |
| \-\-pagination-arrow-bd-color | 分页箭头边框颜色（outline 风格） |
| \-\-pagination-arrow-bd-color-hover | 分页箭头鼠标悬停边框颜色（outline 风格） |
| \-\-pagination-arrow-bd-color-active | 分页箭头鼠标按下边框颜色（outline 风格） |
| \-\-pagination-arrow-bd-color-current | 当前页箭头边框颜色（outline 风格） |
| \-\-pagination-arrow-bd-color-disabled | 分页箭头禁用边框颜色（outline 风格） |
| \-\-pagination-arrow-bg-color | 分页箭头背景色（solid 风格） |
| \-\-pagination-arrow-bg-color-hover | 分页箭头鼠标悬停背景色（solid 风格） |
| \-\-pagination-arrow-bg-color-active | 分页箭头鼠标按下背景色（solid 风格） |
| \-\-pagination-arrow-bg-color-current | 当前页箭头背景色（solid 风格） |
| \-\-pagination-arrow-bg-color-disabled | 分页箭头禁用背景色（solid 风格） |
