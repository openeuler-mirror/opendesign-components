### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-anchor-line-width | 锚点线宽度 |
| \-\-anchor-line-bg-color | 锚点线背景色 |
| \-\-anchor-line-gap | 锚点线与项目间距 |
| \-\-anchor-indicator-width | 指示器宽度 |
| \-\-anchor-indicator-height | 指示器高度 |
| \-\-anchor-indicator-bg-color | 指示器背景色 |
| \-\-anchor-circle-size | 圆点尺寸 |
| \-\-anchor-circle-ring-width | 圆点环宽 |
| \-\-anchor-circle-gap | 圆点间距 |
| \-\-anchor-bg-color ^[1.2.0](primary) | 水平锚点背景色 |
| \-\-anchor-z-index ^[1.2.0](primary) | 水平锚点层级 |
| \-\-anchor-offset-top ^[1.2.0](primary) | 水平锚点吸顶偏移 |
| \-\-anchor-x-overflown-bg-color ^[1.2.0](primary) | 水平溢出遮罩背景色 |
| \-\-anchor-x-overflown-width ^[1.2.0](primary) | 水平溢出遮罩宽度 |
| \-\-anchor-content-max-width ^[1.2.0](primary) | 水平锚点内容最大宽度 |
| \-\-anchor-item-min-width | 锚点项最小宽度 |
| \-\-anchor-item-link-color | 锚点项链接文字颜色 |
| \-\-anchor-item-link-color-active | 锚点项链接文字颜色(激活) |
| \-\-anchor-item-link-color-hover | 锚点项链接文字颜色(hover) |
| \-\-anchor-item-link-color-press | 锚点项链接文字颜色(press) |
| \-\-anchor-item-link-color-disabled | 锚点项链接文字颜色(禁用) |
| \-\-anchor-item-max-row | 锚点项最大行数 |
| \-\-anchor-item-link-text-size | 锚点项链接文字大小 |
| \-\-anchor-item-link-text-height | 锚点项链接文字行高 |
| \-\-anchor-item-sub-link-text-size | 锚点项子链接文字大小 |
| \-\-anchor-item-sub-link-text-height | 锚点项子链接文字行高 |
| \-\-anchor-item-link-padding-h | 锚点项链接内边距(水平) |
| \-\-anchor-item-link-padding-v | 锚点项链接内边距(垂直) |
| \-\-anchor-item-sub-link-padding-v | 锚点项子链接内边距(垂直) |
| \-\-anchor-item-link-radius | 锚点项链接圆角 |
| \-\-anchor-item-text-indent | 锚点项文字缩进 |
| \-\-anchor-item-bg-color-hover | 锚点项背景色(hover，菜单模式) |
| \-\-anchor-item-bg-color-press | 锚点项背景色(press，菜单模式) |
| \-\-anchor-item-gap | 锚点项间距(水平模式) |
| \-\-anchor-item-depth ⚠ 运行时赋值 | 锚点项缩进层级（由组件内部计算，不可通过 CSS 覆盖） |
| \-\-anchor-popover-max-width | 锚点弹出框最大宽度 |
