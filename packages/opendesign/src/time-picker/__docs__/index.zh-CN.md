## API

### CSS 变量

| CSS 变量                                              | 描述                           | 默认值                         |
| ----------------------------------------------------- | ------------------------------ | ------------------------------ |
| `--time-range-picker-bg-color-focus` | 范围选择器聚焦时背景色         | `var(--o-color-control2-light)` |
| `--time-panel-bg`                    | 面板背景色                     | `var(--o-color-fill2)`         |
| `--time-panel-shadow`                | 面板阴影                       | `var(--o-shadow-2)`            |
| `--time-panel-content-padding`       | 面板内容内间距                 | `6px 0`                        |
| `--time-panel-footer-padding`        | 面板底部内间距                 | `8px 16px`                     |
| `--time-panel-item-height`           | 时间项高度                     | `24px`                         |
| `--time-panel-item-width`            | 时间项宽度                     | `40px`                         |
| `--time-panel-item-color`            | 时间项文字颜色                 | `var(--o-color-info1)`         |
| `--time-panel-item-color-active`     | 激活时间项文字颜色             | `var(--o-color-primary1)`      |
| `--time-panel-item-color-disabled`   | 禁用时间项文字颜色             | `var(--o-color-info4)`         |
| `--time-panel-item-bg-hover`         | 时间项 hover 背景色            | `var(--o-color-control2-light)` |
| `--time-panel-item-bg-active`        | 激活时间项背景色               | `var(--o-color-control3-light)` |
| `--time-panel-item-today-border`     | 当前时间项边框                 | `1px solid var(--o-color-primary1)` |
| `--time-panel-item-gap`              | 时间项间距                     | `4px`                          |
| `--time-panel-col-width`             | 时间列宽度                     | `96px`                         |
| `--time-panel-col-show-item-count`   | 时间列可见项数量               | `8`                            |
| `--time-panel-text-size`             | 面板文字字号                   | `var(--o-font_size-tip1)`      |
| `--time-panel-text-height`           | 面板文字行高                   | `var(--o-line_height-tip1)`    |
| `--time-panel-item-text-size`        | 时间项文字字号                 | `var(--o-font_size-tip1)`      |
| `--time-panel-item-text-height`      | 时间项文字行高                 | `var(--o-line_height-tip1)`    |
