## Api

### CSS 变量

| CSS 变量 | 描述 |
| --- | --- |
| \-\-select-text-size | 选择器文字大小 |
| \-\-select-text-height | 选择器文字行高 |
| \-\-select-color | 选择器文字颜色 |
| \-\-select-color-hover | 选择器鼠标悬停文字颜色 |
| \-\-select-color-focus | 选择器聚焦文字颜色 |
| \-\-select-color-disabled | 选择器禁用文字颜色 |
| \-\-select-placeholder | 选择器占位文字颜色 |
| \-\-select-bg-color | 选择器背景色 |
| \-\-select-bg-color-hover | 选择器鼠标悬停背景色 |
| \-\-select-bg-color-focus | 选择器聚焦背景色 |
| \-\-select-bg-color-disabled | 选择器禁用背景色 |
| \-\-select-bd-color | 选择器边框颜色 |
| \-\-select-bd-color-hover | 选择器鼠标悬停边框颜色 |
| \-\-select-bd-color-focus | 选择器聚焦边框颜色 |
| \-\-select-bd-color-disabled | 选择器禁用边框颜色 |
| \-\-select-icon-color | 选择器图标颜色 |
| \-\-select-icon-color-disabled | 选择器禁用图标颜色 |
| \-\-select-icon-gap | 选择器图标与文字间距 |
| \-\-select-icon-size | 选择器图标大小 |
| \-\-select-padding | 选择器内边距 |
| \-\-select-radius | 选择器圆角 ⚠ `round` prop 赋值时覆盖为 inline 样式 |
| \-\-select-height | 选择器高度 |
| \-\-select-tag-bg-color | 多选标签背景色 |
| \-\-select-tag-radius | 多选标签圆角 |
| \-\-select-tag-text-size | 多选标签文字大小 |
| \-\-select-tag-text-height | 多选标签文字行高 |
| \-\-select-tag-padding | 多选标签内边距 |
| \-\-select-tag-margin | 多选标签外边距 |
| \-\-select-tag-popover-max-width | 多选标签弹出层最大宽度 |
| \-\-select-multiple-max-height | 多选模式最大高度 |
| \-\-select-multiple-padding | 多选模式内边距 |
| \-\-select-empty-padding | 空选项内边距 |
